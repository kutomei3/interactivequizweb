How ./questions_deck/ Multi-Deck Sync Works
  • Automatic Server Mode (VS Code Live Server / python -m http.server): Create a folder named questions_deck next to this HTML file and drop any number of .json files inside. The app automatically scans ./questions_deck/ (or ./questions_deck/index.json) and lists all your decks in the sidebar!
  • Zero-Server Mode (Direct file:// double-click): Click "Link questions_deck Folder" in the top bar and select your questions_deck folder once. Every .json file inside will appear in your Deck Library, and clicking Rescan Folder reloads any edits immediately.
